ORBIS WEBSITE — STAGE 1 FOUNDATION

This package is based on the supplied ORBIS Stage 4 project. Existing Stage 3/4 files,
character assets, and feature scripts are preserved. Stage 1 adds the shared visual
foundation, gate atmosphere, responsive interaction polish, reduced-motion support,
and navigation behavior.

GITHUB PAGES
1. Extract this ZIP.
2. Open the folder ORBIS_Website_Stage4.
3. Upload the CONTENTS of that folder to the ROOT of your GitHub repository.
   The repository root should contain index.html plus css/, js/, and assets/.
4. In GitHub: Settings > Pages > Deploy from a branch > main > /(root).

IMPORTANT
- Keep folder names exactly: css, js, assets.
- Do not upload the outer folder as an extra nested directory.
- Open index.html locally for a quick check, then test the published GitHub Pages URL.
- External Google Fonts require an internet connection; system fallback fonts remain available.
