# ORBIS Website — Stage 1 Foundation

This is the first-stage foundation built on the supplied ORBIS Stage 4 project. Existing Stage 3/4 character profiles, scripts, styles, and image assets are preserved.

## Stage 1 additions
- Refined gate atmosphere with floating ambient particles and layered portal effects
- Improved button, navigation, card, and page-transition feedback
- Mobile navigation close behavior and browser hash navigation support
- Keyboard focus styling and `prefers-reduced-motion` support
- Shared styling foundation for later stages

## GitHub Pages deployment
1. Extract the ZIP.
2. Open `ORBIS_Website_Stage1`.
3. Upload the **contents** of this folder to the root of your GitHub repository. `index.html`, `css/`, `js/`, and `assets/` must sit together at the repository root.
4. Go to **Settings → Pages → Deploy from a branch → main → /(root)**.

Keep folder names exactly as supplied. Do not upload only `index.html` or nest the project folder one level too deep.
